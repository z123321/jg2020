1. 依赖安装 [折叠]

SQLite 为 Python 内置库，无需额外安装；MySQL 需要 pymysql

✓已复制 
pip install pymysql

2. 导入模块 [折叠]

✓已复制 
from db_util import get_db_instance, migrate_table

3. 配置说明 [折叠]

MySQL 配置

✓已复制 
cfg_mysql = {
    "db_type": "mysql",
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "你的密码",
    "charset": "utf8mb4"  # 可选参数
}

MySQL 的 db_name 为数据库名称，例如 crypto_db

SQLite 配置

✓已复制 
cfg_sqlite = {
    "db_type": "sqlite"
}

SQLite 的 db_name 是数据库文件路径，例如 ./crypto_raw.db，打开文件自动建库，不需要单独执行建库语句。

4. 获取数据库实例（工厂方法） [折叠]

✓已复制 
db = get_db_instance(cfg_mysql)
# 或者切换为sqlite
db = get_db_instance(cfg_sqlite)

拿到实例后，所有方法签名完全一致，切换数据库仅修改配置，业务代码无需改动。

5. API 方法说明 [折叠]

⚠️ 安全提醒：表名、字段名使用字符串拼接，仅限内部可控项目，不要直接接收外网原始输入；where 值使用参数绑定，防注入。

5.1 create_database 创建数据库

仅 MySQL 生效，SQLite 内部是空实现

✓已复制 
db.create_database("crypto_db")

5.2 create_table 创建表

参数：db_name、table_name、col_def 字段定义字典

✓已复制 
ohlcv_table_def = {
    "exchange": "VARCHAR(32) NOT NULL",
    "symbol": "VARCHAR(32) NOT NULL",
    "timeframe": "VARCHAR(16) NOT NULL",
    "ts": "BIGINT NOT NULL",
    "open": "DOUBLE",
    "high": "DOUBLE",
    "low": "DOUBLE",
    "close": "DOUBLE",
    "volume": "DOUBLE",
    "PRIMARY KEY": "(exchange, symbol, timeframe, ts)"
}
db.create_table("crypto_db", "ohlcv", ohlcv_table_def)

5.3 insert_one 单条插入

✓已复制 
row = {
    "exchange":"okx",
    "symbol":"BTC/USDT",
    "timeframe":"1m",
    "ts":1700000000000,
    "open":40000,
    "high":40100,
    "low":39900,
    "close":40050,
    "volume":123.45
}
last_id = db.insert_one("crypto_db", "ohlcv", row)

5.4 insert_batch 批量插入（主键冲突会报错）

✓已复制 
rows = [row1, row2, row3]
cnt = db.insert_batch("crypto_db", "ohlcv", rows)

5.5 insert_duplicate 单条插入，主键冲突自动更新（K线同步推荐）

✓已复制 
db.insert_duplicate("crypto_db", "ohlcv", row)

5.6 insert_batch_duplicate 批量插入，冲突更新（主力同步方法）

✓已复制 
cnt = db.insert_batch_duplicate("crypto_db", "ohlcv", rows)

5.7 select 普通查询

  • cols：查询字段列表，None=全部字段
  • where：等值AND条件字典
  • order_by：排序字符串
  • limit：返回条数
✓已复制 
res = db.select(
    db_name="crypto_db",
    table_name="ohlcv",
    cols=["ts","close"],
    where={"exchange":"okx","symbol":"BTC/USDT"},
    order_by="ts ASC",
    limit=100
)

5.8 select_page 分页查询

返回结构：{"total":总条数, "page":当前页, "page_size":每页大小, "list":数据数组}

✓已复制 
res = db.select_page(
    db_name="crypto_db",
    table_name="ohlcv",
    cols=["ts","open","close"],
    where={"exchange":"okx","symbol":"BTC/USDT","timeframe":"1m"},
    order_by="ts ASC",
    page=1,
    page_size=50
)
print(res["total"])
print(res["list"])

5.9 update 更新数据

✓已复制 
cnt = db.update(
    db_name="crypto_db",
    table_name="ohlcv",
    set_data={"close":40080},
    where={"ts":1700000000000}
)

5.10 delete 删除数据

✓已复制 
cnt = db.delete(
    db_name="crypto_db",
    table_name="ohlcv",
    where={"ts":1700000000000}
)

6. migrate_table 双向迁移（sqlite ↔ mysql） [折叠]

迁移前目标表必须提前建好，字段、主键结构保持一致；分页读取，分批写入，不会撑爆内存；主键冲突自动更新，支持重复执行。
✓已复制 
src_cfg = {"db_type": "sqlite"}
dst_cfg = {
    "db_type": "mysql",
    "host":"127.0.0.1",
    "port":3306,
    "user":"root",
    "password":"xxx"
}

total = migrate_table(
    source_cfg=src_cfg,
    target_cfg=dst_cfg,
    source_db_name="crypto_raw.db",
    target_db_name="crypto_db",
    table_name="ohlcv",
    where={"exchange":"okx","symbol":"BTC/USDT","timeframe":"1m"},
    page_size=2000
)
print(f"迁移总数：{total}")

反向迁移 MySQL → SQLite，只需要交换 src_cfg 和 dst_cfg。page_size 推荐：2000 ~ 5000

7. 常见坑说明 [折叠]

  • SQLite 字段类型只是语法兼容，没有 MySQL 严格限制；冲突更新语法底层自动区分，上层不用关心。
  • where 条件目前只支持等值 AND 查询，不支持 > < OR IN 等复杂条件，复杂SQL需要自行扩展。
  • 大量K线同步优先使用 insert_batch_duplicate，性能远高于循环单条写入。
  • 分页查询 page 小于1会自动修正为1。

8. 完整极简示例 [折叠]

✓已复制 
from db_util import get_db_instance

cfg = {
    "db_type": "sqlite"
}
db = get_db_instance(cfg)

table_def = {
    "exchange":"VARCHAR(32) NOT NULL",
    "symbol":"VARCHAR(32) NOT NULL",
    "ts":"BIGINT NOT NULL PRIMARY KEY",
    "close":"DOUBLE"
}
db.create_table("test.db", "ohlcv", table_def)

db.insert_duplicate("test.db", "ohlcv", {
    "exchange":"okx",
    "symbol":"BTC/USDT",
    "ts":1700000000000,
    "close":40000
})

data = db.select_page(
    "test.db",
    "ohlcv",
    where={"symbol":"BTC/USDT"},
    page=1,
    page_size=10
)
print(data)
